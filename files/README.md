# Bean & Bloom Café

Responsive café website built with HTML5, CSS3 and vanilla JavaScript (no frameworks).

## Features
- Sticky header, mobile hamburger menu, active-section highlighting
- Hero, featured products, testimonials, About, Menu, Contact, Footer
- Menu category filtering (JavaScript) with prices in NPR
- Contact form validation with a success message (no backend)
- Accessible: semantic HTML, skip link, focus styles, reduced-motion support
- Lightweight SVG images in `images/`; replace them with real photos (JPG/WebP) for launch

## Run
Open `index.html` in a browser.

## Deploy
- **GitHub Pages:** push to a repo, then Settings → Pages → deploy from `main` / root.
- **Netlify:** drag the `bean-and-bloom` folder onto app.netlify.com/drop.
